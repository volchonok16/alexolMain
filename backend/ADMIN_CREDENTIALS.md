# 🔐 Учетные данные администратора

## Автоматическое создание

При первом запуске бэкенда админ создаётся **автоматически**, если в базе данных нет пользователей.

## Учетные данные по умолчанию

- **Логин**: `alex`
- **Пароль**: `Triu546r!)`
- **Роль**: `admin`
- **Имя**: `Alex Administrator`

## Как это работает

1. При запуске сервера выполняется функция `initAdmin()`
2. Проверяется наличие пользователей в базе данных
3. Если пользователей нет — создаётся дефолтный админ
4. Если пользователи уже есть — пропускается

## Ручное управление

Если нужно вручную создать или пересоздать админа:

```bash
# Создать админа (если его нет)
npx tsx scripts/createAdmin.ts

# Удалить всех пользователей и создать нового админа
npx tsx scripts/resetAdmin.ts
```

## Безопасность

⚠️ **Важно**: Рекомендуется сменить пароль после первого входа!
